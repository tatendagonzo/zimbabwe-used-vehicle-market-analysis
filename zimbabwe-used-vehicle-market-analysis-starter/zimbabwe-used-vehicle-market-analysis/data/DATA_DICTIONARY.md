# Data Dictionary

| Field | Description | Type |
|---|---|---|
| listing_id | Project-assigned unique row identifier | Text |
| make | Vehicle manufacturer | Text |
| model | Vehicle model | Text |
| year | Model year | Integer |
| price | Advertised asking price | Numeric |
| currency | Currency shown by listing | Text |
| mileage_km | Advertised mileage in kilometres | Numeric |
| transmission | Advertised transmission; blank if unavailable | Text |
| fuel_type | Advertised fuel type; blank if unavailable | Text |
| body_type | Vehicle body category | Text |
| location | Advertised location | Text |
| date_collected | Date the record was captured | Date |
| source_name | Website where listing was found | Text |
| listing_url | Source results page URL | URL |
| notes | Context such as negotiable, before duty or missing card details | Text |
